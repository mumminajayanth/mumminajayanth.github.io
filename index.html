SCENE 01INT. PROJECT REEL — NOW SCREENING

Flagship project

RAG-Based PDF Chatbot

Now screening
Type
Retrieval-Augmented Generation (LLM app)
Stack
Python, LangChain, FAISS, HuggingFace, Groq LLaMA, Streamlit

Upload any PDF and ask it questions in plain English. The app chunks the document, embeds each chunk with HuggingFace's all-MiniLM-L6-v2 model, and indexes them in FAISS for fast similarity search. On each query, the most relevant chunks are retrieved and passed to a Groq-hosted LLaMA model to generate a grounded answer — wrapped in a simple Streamlit interface. Later extended with Groq Vision so it can also read and answer questions about images and diagrams inside the document.

LangChain FAISS HuggingFace Embeddings Groq LLaMA Streamlit
